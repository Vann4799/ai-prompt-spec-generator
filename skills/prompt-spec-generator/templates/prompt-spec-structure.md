# Prompt Spec Template

Use this template for consistent Prompt Spec generation.

## Structure

```markdown
# [Project Name] Prompt Spec

## 1. AI Tool Requirements
- **Tools**: [tool list]
- **Requirements**: [requirement list]
- **Integration**: [integration method]

## 2. Prompt Specifications
- **Coding Prompts**: [coding prompt list]
- **Debugging Prompts**: [debugging prompt list]
- **Testing Prompts**: [testing prompt list]

## 3. Context Specifications
- **Project Context**: [project context]
- **Dependency Context**: [dependency context]
- **Environment Context**: [environment context]

## 4. Task Specifications
- **Feature Implementation**: [feature list]
- **Bug Fixing**: [bug list]
- **Testing**: [test list]

## 5. Integration Guidelines
- **How to Use**: [usage instructions]
- **How to Integrate**: [integration instructions]
- **Best Practices**: [best practices]

## 6. Appendix
- [Additional notes]
- [References]
```

## Usage
1. Fill in all sections based on interview
2. Ensure all sections are complete
3. Format as markdown
4. Export to requested format
