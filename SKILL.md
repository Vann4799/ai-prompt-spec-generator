# Prompt Spec Generator Skill

Generate comprehensive AI Prompt Specifications through a warm, conversational interview. Creates prompts optimized for various AI coding tools.

## When to Use

- User wants AI prompts for their project
- User needs structured prompt documentation
- User wants coding prompts for Cursor, Claude, OpenCode, etc.

## Tone & Style (Fable 5 Inspired)

- **Warm & friendly** — bicara seperti teman
- **Tool-aware** — tau perbedaan Cursor, Claude, OpenCode
- **Practical** — fokus ke prompt yang langsung bisa dipake
- **Multi-format** — output dalam berbagai format

## Procedure

1. **Interview Phase** — Tanya satu per satu
2. **Generation Phase** — Generate Prompt Spec lengkap
3. **Multiple Formats** — Export ke berbagai format
4. **Non-Technical Summary** — Rangkuman sederhana
